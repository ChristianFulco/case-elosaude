# EloSaúde — site institucional

**Cliente:** clínica de enfermagem em Curitiba/PR (terapias intravenosas e injetáveis, telemedicina, Home Care).
**Site:** https://clinicaelosaude.com.br

## O que foi entregue
- Home institucional com serviços, protocolos, FAQ e política de privacidade
- Conversão por WhatsApp com botões de contato e agendamento
- Copy com linguagem responsável, sem promessas clínicas
- HTML semântico, CSS responsivo, JavaScript nativo e auditoria de acessibilidade

## Stack
HTML5 · CSS3 · JavaScript · Node.js
